# 哪吒：独立立绘、Q版战斗与三头六臂

角色立绘按本轮图一保留脸部、红白服装、火尖枪、乾坤圈和红绫，背景改成浅杏色绢纸与淡金莲纹。地图人物卡、圆形部队头像和战斗人物面板使用这张立绘的独立裁切。战斗使用图二比例的 Q 版动作资源，角色脚下没有风火轮。

## 人物面板

技能区向下延长 55 个设计像素，固定显示战技、终结技、军略、被动四个图标及名称。悬停给出对应说明，被动明确标注自动生效。技能卡只供查看，点击不触发技能，不穿透到地图。部队区仍为编队1、编队2、编队3，按原槽位显示兵种和人数，空编队留白。最下方法宝为四个空槽；当前没有实际装备数据，故不填入虚构法宝。

## 美术与帧时序

- 立绘：`assets/characters/nezha/v3/portrait.png`，1024×1536。
- Q版基础动作：`actions.png`，1024×1536，4列×6行，共24个角色姿势；依次为待机、奔跑、受击、倒地、投圈、施法，每行4帧。终结技与地图施法暂时共享施法姿势，但各自使用独立技能特效和时序。
- 普攻：`attack.png`，1536×1024，4列×4行，共16个角色姿势，覆盖蓄力、两段出枪、回收。
- 三头六臂：`three_heads_fx.png`，1536×1024，4列×3行，12帧金色法相与碎瓣。它是透明特效层，显示在角色后方；没有把实体角色重复画入特效。
- 乾坤圈、火莲、灼烧和枪焰继续使用已接入的独立特效资源。运行时共使用40个不同角色帧与36个不同特效帧。

`data/nezha_art_v3.json` 保存每格的源矩形、透明轮廓、脚底锚点、帧时长和事件。`tools/measure_nezha_v3.py` 只测量源图，不改动图片像素。旧版资源和清单保留供回溯。

普通攻击总长0.845秒。各帧时长（毫秒）为65、55、55、50、45、60、45、45、45、65、50、50、55、55、45、60。第6帧（0.270秒）和第10帧（0.465秒）各结算一段0.5倍物攻，并同步枪尖特效。实际结算由60Hz战斗演算驱动，暂停和加速同时影响动画与伤害；渲染掉帧不漏判伤害。

更多动作帧提供更连贯的姿势过渡；起手、接触帧、收招时长、脚底对齐同样影响流畅度。当前普攻已从6帧增加到16帧，其他动作仍可按后续美术需求继续补帧。

## 被动结算

`data/unit_catalog.json` 中哪吒被动为 `three_heads_six_arms`。暂定溅射系数0.35、半径140战斗坐标单位，以被命中的主目标为中心。

每次有效普攻接触，对半径内其他存活敌军按当前攻击段系数×0.35计算物理伤害，并分别结算各目标物防。主目标不会重复受到溅射，友军与已退场单位不会受伤，溅射不递归、不增加普攻命中次数、不传播灼烧。击杀主目标的一击仍触发溅射，普攻打空则不触发。双方哪吒使用相同规则，部队士兵不会继承主将的普攻触发器。溅射战损正常累计击杀和士气。

原被动魔防+15已移除，哪吒基础魔防恢复为30。普攻每累计三次命中叠加灼烧的既有规则保留。
