# 朝歌战斗与地图技能测试场

默认启动只加载哪吒与闻仲两支敌对部队，部署在朝歌南侧的真实相邻陆地格上，各2400兵。人物数据、地图技能效果和战损直接进入战斗结算。

## 界面与操作

地图常驻界面只保留左侧人物面板、小地图、结束回合，以及地图上的部队名牌和朝歌标识。顶部资源、地域导航、右侧面板、底部武将条与操作按钮、小地图标题和侧边按钮都已隐藏，对应的旧点击遮挡也已移除。

人物面板由650加长到812个设计像素。立绘距外框至少20像素，避免覆盖边框；顶部去掉状态行，“士气”与50/100同排，人物头像区缩短28像素，属性与编队统一44像素行距；技能为64×64的满幅二次元插画，去掉图标下的技能名，悬停显示名字与完整说明。法宝四格为56×56，未装备时显示统一的莲纹占位，悬停明确显示“未装备”。部队区标题为“部队”，三个编队槽仍按实际兵种与数量显示，空槽留白。

- 左键部队或头像选中；1、2也可切换哪吒和闻仲。
- 点击第三个技能图标或按Q进入地图技能选点，左键目标部队或地格施放，右键/Esc取消。
- 哪吒火莲焚阵直接减少闻仲的地图兵力；闻仲雷印镇军降低哪吒物防、魔防，效果带入随后战斗。
- 相邻时右键敌方部队/头像，或按B，进入两支实际部队的战斗。施法或战斗消耗本队本回合行动。
- 空地左键规划路线，右键下达行军；滚轮缩放，中键/右键拖图，小地图定位继续可用。
- 结束回合或E恢复行动，并将这两支测试部队补满2400兵，便于重复测试。地图减益仍按原来的回合时限消退。

该测试场不自动保存，隐藏的保存/读取快捷键在测试场停用，避免将测试状态写入战役存档。战役数据保留；`--campaign`或将主场景的`start_in_test_scenario`设为false可加载原战役编队。当前精简界面不展示经营操作。

## 终结技优先级

士气达到100、列阵结束且主将存活时，R或终结技按钮立即取消自己的普攻、普通战技、移动或受击表现，切入终结技动作。双方采用相同规则。终结技仍按自己的读条和命中帧结算伤害，不把读条变成瞬发伤害。

已结算的伤害保留；被打断普攻的剩余命中、未结算战技和飞行表现会取消，既有灼烧继续按原规则结算。一次释放只扣一次士气，正在执行的终结技不能被重复按键重置；暂停、死亡、列阵阶段与战斗结束仍遵守原有门槛。

## 资源与验证

`assets/ui/skills/hero_icons.png`是一张3×3不透明插画图集，包含哪吒四技、闻仲四技和空法宝纹样；运行时按格裁切并启用mipmap以保持缩小时的清晰度。没有把占位法宝算作实际装备。

`tests/chaoge_check.gd`覆盖双方地图技能、真实战损、回合恢复、八种动作阶段的终结技打断、伤害取消和阵营显示。`tests/chaoge_runtime.gd`通过真实窗口输入验证图标、悬停、1280×720缩放、技能选点、右键接战、R打断、战后返回与恢复测试兵力。预览截图和报告保存在`previews/chaoge-test/`。

旧战役的规则、导航、哪吒灼烧与溅射检查继续适用。旧版录制或战役交互脚本需使用`--campaign`运行；新测试场使用上面的专用脚本。
