# 哪吒美术资源 · 第二版

本轮交付为与现有 Godot 2D 帧动画管线配套的战斗造型基准、人物关键帧、独立特效和动画预览。美术采用已选定的国风幻想卡牌立绘方向，统一朱红、象牙白、鎏金配色，以及双髻、莲瓣轻甲、混天绫、乾坤圈和火尖枪。按最新反馈，**当前版本的立绘、战斗基准和所有人物动作均取消风火轮**。

此套资源与技能规则已接入 Godot 游戏。大地图主将面板、底部人物卡和战斗面板使用第二版立绘裁切；战场使用完整的六帧人物动作、受击及倒地动作，技能使用独立特效。大地图火莲焚阵播放结印动作与目标火柱。`scripts/nezha_art.gd` 负责图集采样，实战逻辑由固定 60 Hz 模拟驱动。

启动 `project.godot` 或运行 `./launch.sh`，选择哪吒后按 **B** 进入演武；乾坤圈自动施放，士气达到 100 时按 **R** 释放三昧真火。大地图按 **Q** 选择目标施放火莲焚阵。实战截图位于 `previews/nezha/runtime/`；下方的 HTML 和 MP4 仍是独立美术预览。

## 资源入口

- 战斗造型基准：`assets/characters/nezha/nezha_battle_master_v2.png`，1024×1536，RGBA，朝右三分之四视角。
- 图集索引、每帧取样区、脚底锚点、头像裁切区与动作事件：`data/nezha_art_v2.json`。
- 生成来源和提示记录：`data/nezha_art_generation.json`。
- 可交互预览：在项目根目录执行 `python3 -m http.server 8765`，浏览器访问 `http://127.0.0.1:8765/previews/nezha/`。
- 直接观看：`previews/nezha/nezha_actions_v2.mp4`，约 19 秒。
- 实机演示：`previews/nezha/nezha_gameplay_v2.mp4`，33.8 秒，1080p / 30 FPS，包含游戏原声、大地图火莲焚阵、列阵冲锋、乾坤圈、普攻灼烧、三昧真火和结算返回。终结技在约第 19 秒。来自 Godot Movie Maker 对真实游戏视口的录制，非硬件帧率测量；演示起点设置在敌方据点旁的合法陆地，技能伤害与士气沿用正常游戏规则，未写入玩家存档。

先前含风火轮的两张 `*_v1.png` 保留为历史原稿，不被新索引、预览和本版导出资源包引用。

## 人物动作

七张人物图集均为 1536×1024、三列两行，每张六帧，共 42 帧。受击和倒地共用一张图集，每组各三帧。均使用透明 PNG，朝左显示可由运行时镜像完成。

| 文件（`assets/characters/nezha/animations/`） | 动作 | 时长 / 关键节点 |
| --- | --- | --- |
| `idle.png` | 待机呼吸、红绫轻动 | 1.20 秒循环 |
| `run.png` | 朝右奔跑 | 0.54 秒循环 |
| `attack.png` | 蓄势、短刺、回枪、挑刺、收招 | 0.74 秒；0.24 秒短刺，0.44 秒挑刺 |
| `qiankun.png` | 取圈、投圈、空手随势、迎接、收圈 | 1.04 秒；0.36 秒离手，0.86 秒回收 |
| `samadhi.png` | 蓄势、跃起、下刺、落地、收招 | 1.30 秒；0.40 秒起跳，0.84 秒落枪 |
| `fire_field.png` | 立枪、结印、指向目标、维持、收势 | 1.36 秒；0.62 秒施放 |
| `recovery.png` | 上排受击三帧，下排倒地三帧 | 受击 0.35 秒，倒地 1.08 秒后保持末帧 |

这些是逐帧绘制的动作关键姿势，适合当前帧动画方案。它们不是骨骼绑定文件，也不是高帧率补间后的动画。后续若提高运动流畅度，可在同一造型与事件时点下补绘过渡帧。

## 独立特效

| 文件（`assets/characters/nezha/effects/`） | 内容 | 帧数 |
| --- | --- | --- |
| `combat.png` | 第一行枪焰与命中；第二行乾坤圈飞行；第三行灼烧；第四行莲花护体 | 4×4，共 16 帧；原图 1254×1254 |
| `samadhi.png` | 法印、火蕾、展瓣、爆发、碎瓣、余烬 | 6 帧；1536×1024 |
| `fire_field.png` | 目标莲印、火蕾、三柱升起、爆发、回落、消散 | 6 帧；1536×1024 |

乾坤圈在施法人物图集的离手阶段消失，由投射物特效绘制，回收时重新出现在手中。普攻特效使用枪尖挂点；终结技在落枪帧进入火莲爆发阶段。人物与特效分别存放，伤害结算由战斗事件驱动，独立于显示帧率。暂停和倍速同时作用于动作、投射物、灼烧计时和伤害。

## 已确定的技能方向

- 普攻：火尖枪连刺，每累计三次普攻命中附一层灼烧。
- 自动技能：乾坤圈穿击前方小范围敌军，造成法术伤害并附灼烧。
- 终结技：三昧真火造成范围法术伤害，消耗目标灼烧层数增加爆发；灼烧最多三层，额外收益设上限。
- 大地图：火莲焚阵消耗本回合行动力，对范围内敌方据点守军造成兵力伤害。
- 被动：莲花化身保留自身魔防加成，以青白金莲瓣表现法术抵抗。

当前可调数值位于 `data/unit_catalog.json`：

| 行为 | 当前实现 |
| --- | --- |
| 火尖枪连刺 | 0.24 / 0.44 秒各命中一次，每次为 0.5 倍物攻；三次有效命中附一层灼烧，空挥不累计 |
| 灼烧 | 同一施法者最多三层，持续四秒，每秒每层 0.12 倍魔攻，经过目标魔防减免；叠层刷新持续时间，不重置下一次跳伤 |
| 乾坤圈 | 0.36 秒离手，0.61 秒命中，0.86 秒回收；前方 350 距离、中心线两侧各 90 的走廊，1.05 倍魔攻并附一层灼烧，冷却 5.8 秒 |
| 三昧真火 | 消耗 100 士气；0.84 秒对锁定区域结算，半径 520，基础 2.6 倍魔攻；每层自身灼烧增加 0.35 倍，最多三层，结算时消耗 |
| 火莲焚阵 | 射程五格、范围两格；0.62 秒生成目标法阵、1.12 秒火柱爆发并结算，1.85 秒恢复行军显示；消耗本轮行动，不直接占领 |
| 莲花化身 | 自身魔防 +15，受到法术伤害时显示青白金莲瓣 |

灼烧继续使用原战斗的击杀士气规则；目标阵亡后清除，战斗结束后停止跳伤。它属于本场战斗状态，不写入大地图存档。施放大地图技能期间锁定切换部队、再次施法、行军、结束回合、进入据点/战斗及存读档，避免重复结算。

## 接入与验证

运行 `python tools/measure_nezha_art.py` 可重新测量图集并生成 JSON 索引、浏览器索引和 `previews/nezha/asset_check.json`。脚本只读取源 PNG 的透明通道，不改写图像像素。取样边界依据透明间隔测量，不能直接假定所有图集都能按整数 256 或 512 等分。

同一角色动作内采用统一缩放，跳跃帧保留相对地面的高度，倒地帧保持真实大小。运行时取每帧 `source` 与 `pivot`，按图集 `body_height` 换算显示尺寸。头像以第二版立绘的 `portrait_regions` 裁切，避免把战斗精灵放大作头像。

已检查全部 70 帧非空、取样范围有效，显著不透明像素不触及取样边界。浏览器预览检查覆盖 14 组动画、全部帧、深浅背景、180 像素战斗尺寸、左右朝向和 390 像素宽窄屏；记录在 `previews/nezha/preview_check.json`。这是资源与预览检查，不替代接入后的游戏性能和战斗回归。

接入后的验证环境为 Linux / Godot 4.6.3 / Compatibility / llvmpipe，窗口 1920×1080，并覆盖 1280×720 缩放输入：

- `tests/nezha_check.gd`：511 项，覆盖双段命中时点、空挥、灼烧上限/刷新/到期、跳伤击杀士气、终结技引爆、乾坤圈正反方向、全部 70 帧取样和人物双朝向四角边界。
- `tests/battle_check.gd`：37 项，包含确定性战果、兵力/士气回写、存档往返和 122 实体碰撞压力检查。
- `tests/skills_check.gd`：111 项，覆盖五位武将四技能、属性、地图技能与存档兼容。
- `tests/battle_layout_check.gd`：4277 项，覆盖其余四套角色、等比绘制与战场边界；哪吒由专属图集检查覆盖。
- `tests/battle_runtime.gd`：15 项，真实输入覆盖演武、暂停灼烧与特效、倍速、乾坤圈、R 键三昧真火、真实行军接战和战果返回。
- `tests/skills_runtime.gd`：14 项，覆盖地图选点、无效/取消、延迟结算、施法输入锁定、行动消耗与恢复，以及其他武将技能。
- `tests/navigation_check.gd`：59999 项导航回归通过。

当前游戏截图与报告在 `previews/nezha/runtime/`。软件渲染下完整操作流程约 34 FPS，包含暂停、截图、窗口缩放和倍速，不能当作独立性能基准；此次未完成独立显卡上的 60 FPS 验收，既有硬件的历史性能数据也不代表这套新美术的性能。

复验命令（UI 测试使用独立用户目录）：

```sh
godot --headless --path . --script res://tests/nezha_check.gd
godot --headless --path . --script res://tests/battle_check.gd
godot --headless --path . --script res://tests/skills_check.gd
godot --path . -- --battle-capture=/绝对路径/战斗截图
godot --path . -- --skills-capture=/绝对路径/地图截图
```

实机视频的录制脚本为 `tools/record_nezha_gameplay.gd`：

```sh
godot --path . --script res://tools/record_nezha_gameplay.gd --write-movie /tmp/nezha-gameplay.avi --fixed-fps 30 --disable-vsync
```

录制事件和伤害校验记录在 `previews/nezha/runtime/gameplay-recording.json`，浏览器播放与时间轴检查在 `gameplay-playback-check.json`。
