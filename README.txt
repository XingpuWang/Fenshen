山河 · 九州行军
Godot 4.7 战略大地图交互原型

打开工程
1. 使用 Godot 4.7 导入本文件同目录的 project.godot。
2. 等待首次纹理和字体导入完成，按 F6 运行 main.tscn，或按 F5 运行工程。
3. 已在 Godot 4.7.2 stable 官方版、Compatibility 渲染器中实际运行验证。
4. 本工程自带所有地图、字体、角色和部队素材；运行不需要网络、插件或 Node.js。
   地图源图共约 216 MB，首次导入会花一些时间。推荐桌面端使用。

当前版本
- 保留已经确认的 MapStitch v5 九区底图：宛洛、晋地、齐鲁、关中、幽燕、荆襄、西凉、巴蜀、吴越。
- 原图未重新生成，未重新调色，拼接坐标和裁切与 v5 导出一致。
- 全图使用同一套 64 世界像素半径的六边形坐标，共 11,875 格。
- 40 座城市、27 处关隘、33 个村庄、25 组渡口航线拥有独立归属。
- 3 支可选择的我方部队；哪吒为初始先锋。三支部队均可自由行军、占领、驻守。
- 深色金边界面、人物面板、资源栏、军令面板、九区跳转、小地图、部队卡、回合按钮。
- 行军预览、逐格移动、行动力消耗、过河渡船、回合恢复、战局存读档。

如何操作
左键点击部队或底部卡片：选中部队。
青色六边格：该部队本回合可以到达的范围。
左键点击青色地块：显示金色路线；点击“移动”或按 Enter 执行。
右键点击地块：规划并执行当前回合内的路线。
右键拖动 / 中键拖动 / WASD / 方向键：平移地图。
滚轮：以鼠标所在位置为中心缩放地图。
左键点击城市、关隘、村庄或渡口：显示归属和操作。
“前往附近”：规划到据点相邻位置；较远时只标出本回合可走的一段。
“占领”：必须先到达相邻陆地，并保留至少 1 点行动力。
“驻守”：本回合停止行动，下回合恢复。
“结束回合”或 E：全军行动力恢复。
Space / “定位”：返回当前部队。
G：显示或隐藏基础六边形网格；移动范围仍保留。
F：查看九区全图。
1 / 2 / 3：选择三支部队。
C：占领当前选中的相邻据点。
Esc：取消路线与据点选择。
顶部“存” / F5：保存；“读” / F9：读取。
小地图点击：移动镜头；上方九区名称：跳转对应地区。
F3：开发用地形标定覆盖层，蓝色为水域，红色为山地。

通行规则
山脉、水域不允许普通陆地行军。森林、平原、雪地平原和沙漠平地可以通行。
未占领和敌方城市、关隘、村庄、渡口的占地格全部阻挡。
普通移动还会检查两格之间的地形和据点控制，防止只检查中心点而跨过窄河或关墙。
占领关隘后，开放对应的山口道路；其余山体仍然阻挡。
渡口由两个实际陆地岸边格和一条独立航线组成。只有我方占领后，两岸才加入寻路。
普通行军每格 1 点；渡口过河每次 2 点；占领消耗 1 点。
部队过河时乘舟移动，落点必须为对岸陆地，不会在水面停留。
每一步执行前重新检查归属与占位；路线上的据点失守，会使旧路线停止。
部队不能占据另一支我军所在格。占领只能通过真实的陆地相邻边完成，不能隔山隔河占领。

建议试玩
选择底部“北路军”，点击北方河上的“孟津渡”，点击“前往附近”并移动。
到达后点击“占领”，再选择对岸青色地块，点击“移动”，即可看到乘舟过河。
选择哪吒，点击南方“伊阙关”，沿路接近并占领，即可穿过关隘向南行军。
行动力不足时结束回合继续。原地图的外侧道路保留；当前世界边界以九区范围为准。

工程结构
assets/maps/              MapStitch 原始导出背景、map_data.json 和全图预览
assets/ui/                新生成的人物头像和界面图标
assets/units/             透明部队图与渡船图形
assets/fonts/             Noto CJK 中文字体及 OFL 许可
scenes/main.tscn           入口场景
scripts/game.gd           镜头、输入、逐格行军与军令
scripts/world_model.gd    地形、归属、Dijkstra 寻路、渡口、占领、存档
scripts/map_layer.gd       可达范围、路线、据点标牌与部队选择
scripts/hud.gd             UI 绘制和按钮区域
shaders/hex_grid.gdshader  全图连续六边形网格

data/world.json           已编译的全部通行数据，运行直接读取
data/annotations.json     以原始小图 0..1000 为单位的据点及山地标定
data/terrain_mask.png      可视化地形标定层
data/terrain_reference.jpg 用于重新编译地形的原始全图参考

tools/build_world.cjs     可选的离线通行数据编译器
  修改 data/annotations.json 后，在 tools 目录运行 npm install，然后执行 node build_world.cjs。
  只有重新编译通行数据需要 Node.js + sharp；玩游戏不需要它们。
  不同地图的坐标基点、MapStitch 重叠裁切、山口道路走廊定义保留在编译脚本中。
  地形使用图片水面提取加人工山体轮廓、山口通路标定，在六边格尺度上判定。
  后续若修改底图或格子尺寸，应重新编译并复核 terrain_mask 与 navigation-audit 图。

此版的范围
这是一版可操作的战略地图原型。按当前试玩约定，相邻占领会直接变更归属，尚未加入战斗、守军消耗、敌方 AI 或经营结算。
资源栏、等级与武将属性是界面示例；部队位置、兵力、行动力、据点归属和回合为实际状态。
地图属于中国古代地域意象，部分据点使用便于辨认的历史地名，不是精确历史地理复原。
地图背景里的建筑是已绘制的画面，逻辑据点独立于画面；日后可接入守军、势力、建筑升级和战斗系统。
