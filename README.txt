朝歌测试场（当前默认入口）
只保留哪吒与闻仲，在朝歌南侧相邻陆地测试战斗和地图技能。人物面板加长并收紧立绘边界；技能为无文字的满幅方形插画，法宝为空槽纹样；地图只保留人物面板、小地图与结束回合。
点部队或头像切换，点第三个技能图标或按 Q 选点施法；相邻时右键敌军或按 B 接战，战斗中满士气按 R 可立即打断其他动作释放终结技。结束回合恢复两队兵力与行动，方便反复测试。
点击地图城池可进入内景；朝歌仍属商军，在内景下方「据点」切换到西岐等我方城邑即可营建、升级并结束回合推进工程。返回舆图后继续测试两支部队。

拉取更新后首次运行

大地图部队与斜俯视
部队改为带周字军旗的斜向方阵，使用现有战斗士兵动作帧，显示待机和行军动作。方阵和军旗缩至之前的 45%，随格子半径适配，主要落在单个六边格内；待机、行军和上下船沿用同一套缩放。上方圆形英雄头像连接姓名、实时兵力和兵力条，名牌保持可读大小并贴近部队；选中部队显示金色边框，相邻部队名牌会自动避让。
点击部队、所在格子或名牌均可选中；相邻格子的空地可正常规划路线。地图技能选点时点击名牌，会以该部队所在格为目标。兵损会同步减少方阵中显示的士兵数量。
底图保持原尺寸、原比例，镜头使用等比缩放；仅六边格独立采用约 45 度俯角投影。格子半径由 64 调至 80，同一缩放下宽高增加 25%。可达区域沿用调浅后的深蓝半透明填充、清晰的深蓝边线和柔和外轮廓；行军路线使用流动金色箭簇、发光终点格与旗形标记，接敌路线使用交叉兵刃标记。默认仅显示局部战术范围，G 可显示淡色全图网格。
为保持格子、点击和真实落点一致，导航网格按原地图的地形、据点和渡口标注重新采样；河流、山脉和城池图片不做压缩或移动。旧存档通过原网格坐标转换到附近合法陆地，保留兵力、资源与经营状态。
当前大地图完整截图见 previews/chaoge-test/01-clean-map.png；部队尺寸与交互验证见 previews/map-tactical/compact-armies/，放大格子的导航与旧档迁移报告在 previews/map-tactical/larger-grid/，之前的操作录屏和交互验证报告见 previews/map-tactical/；previews/map-oblique/ 为之前整图压缩方案的历史预览。地图交互验证脚本为 tests/map_presentation_runtime.gd，网格拼接与旧存档验证为 tests/grid_projection_check.gd。

本版视觉更新
内政沿用大地图的暖土黄、木褐、柔和草绿与青蓝河水，建筑朴素，界面采用简洁名牌与木色面板。
大城有内城、外城两重城垣；小城只有一重。大城采用与村庄接近的斜俯视角，墙段在空间中以直角连接，投影到画面后自然倾斜，街道贯通城门。
小城使用用户指定的暖色斜俯视原图，保留河流、水车、桥梁和周边农田，19 处建设用地沿图中的街巷与院落分布。
大城外墙顺着西北坡地和南侧河湾形成不对称的进退轮廓，内城设侧院与退台；街巷以宽窄不同的石路和土路连接院落。
大城内城偏东北，北侧里巷、西侧街市、西南菜圃、南门仓坊与东侧军院形成错落街区；用地嵌在建筑群与院落之间。
朝歌、西岐等九区主城为大城，各有 31 处用地；其余 31 座城市为小城，各有 19 处。
关隘突出高大城楼与山间关墙；渡口沿河分布栈桥和渡船；村庄保留农户、田地与灌溉水道。
每处建设用地拥有固定位置，顺着街道、河岸、田边散落，不画圆圈或方块建设边框。
空地以小木桩示意；“用地”显示全部空地名牌。选择、开关营建目录、建造均不会移动周围建筑。
“协作”显示规则中的邻接连接；经济邻接仍按原地块关系结算，不按画面距离重新计算。
内景滚轮或顶部加减号缩放，中键/右键拖动；顶部“复位”恢复视角。

1080p 性能
当前窗口与设计分辨率为 1920×1080，目标 60 FPS。本机 AMD Radeon Pro 555X / Godot 4.7.2 实测五类内景平均约 60 FPS，大城建满与连续缩放拖动均约 60 FPS。
进入内景时停止后方大地图绘制，界面按变化刷新；macOS 使用完成帧节拍补偿等待时间。528 项交互回归通过，包括升级后的产出显示、地图显隐恢复与战斗往返。
完整条件、P99 帧耗时、单帧尖峰和原始数据见 previews/settlement-performance/report.md；本轮统计覆盖内景与返回大地图静止状态。

先玩这一条路线
启动后是西岐开局，哪吒、南宫适、黄天化位于关中。
点击右上方“西岐内政”，或直接点击地图上的城市、村庄、关隘、渡口，进入内景。
在西岐选择一块“可建造”空地，再选下方“井田”，右侧会显示成本、产出与邻接加成。
点击“兴建”，结束一次回合，井田竣工。选中井田可升级，二级需两回合，三级需三回合。
点击内景左上方的“灵台 · 待修复”开始修复；竣工后全势力钱帛产出增加 10%。
点击左上地名或底部“据点”，可以切换我方村庄和渡口；它们的地块和工匠独立，花费同一份势力资源。
点击顶部“舆图”回到大地图；Esc 优先关闭已展开的菜单与营建目录，再按可退出内景。回到地图后选择青色格子、点击移动继续行军。

经营系统
125 个据点都有独立建设状态：40 城、27 关、33 村、25 渡口。
内景使用大城、小城、村庄、关隘、渡口五套背景。
大城 31 块、小城 19 块、村庄 12 块、关隘 10 块、渡口 7 块；地形资源属性固定、存档可恢复。
城市可同时施工两项，其他据点一项。普通建筑三级：工期 1 / 2 / 3 回合，费用为基础的 1 / 2 / 3 倍。
建造立即从共享府库扣费。新建在竣工后的下一次结算开始生产；升级期间保留原等级产出。
回合顺序：结算当前产出入库 → 推进工程并竣工 → 恢复部队行动力。
失去据点后，其产出和地标效果立即停止，工程暂停；重新占领保留已有建筑和施工进度。
撤工返还一半原始费用，需要再次点击确认。拆除不返资源，需要再次点击确认。

资源与建筑
粮草、木材、金铁、玉石、钱帛、兵员均由我方全势力共享，没有地方仓库和运输限制。
顶部绿色数字是真实的下回合势力产出预测；兵员储备位于内景左下。
井田生产粮草；采木场生产木材；金铁矿场生产金铁；市肆生产钱帛；琢玉坊生产玉石。
仓廪：邻接井田 +25% / +35% / +45%。
民居：邻接市肆 +20% / +30% / +40%。
铸兵坊：邻接采木场和矿场 +20% / +30% / +40%。
军营：每回合生产共享兵员；仅城池与关隘可建。
演武场：邻接军营 +25% / +35% / +45%；仅城池与关隘可建。
丹房：生产玉石，邻接琢玉坊 +25% / +35% / +45%。
阵坛：生产钱帛，邻接生产建筑 +10% / +20% / +30%。
井田在沃土、采木场在林地、矿场在矿脉、琢玉坊在灵地额外 +15%。
按原地块邻接关系生效，内景点击“协作”查看连接；院落画面的距离不直接决定加成。
同类加成来源取最高值，不重复叠加；地形与邻接合计上限 60%。
普通产出随建筑等级线性提高。数据与说明位于 data/buildings.json。
补兵：据点须建成军营，部队在本地两步可通行范围内。每次最多补 500 人，消耗等量共享兵员、每人 2 粮草和 1 行动力。
不可隔着未占领据点、山体或封闭渡口补兵；兵力不得超过该部队上限。

大地图操作与通行
左键点击部队 / 底部卡片：选中部队。左键点击青色地块：显示金色路线；“移动”或 Enter 执行。
右键点击地块：规划并执行路线。右键 / 中键拖动、WASD、方向键平移，滚轮缩放。
据点内景的“前往附近”返回舆图并规划到相邻陆地；远路分回合继续。
占领需要真实的陆地相邻边及 1 点行动力，不能隔山隔河占领。
普通陆地每格 1 点，已占领渡口过河 2 点；渡船从实际岸边出发，落点是对岸陆地。
非我方城市、关隘、村庄、渡口禁止通行；山脉和水面禁止普通陆军通行。
每步移动前复核占位与据点控制，失守会阻断已规划路线。部队不能重叠。
资源共享不改变上述行军限制。
E 结束回合，Space 定位部队，G 显隐六边格，F 全图，1/2/3 选择部队，C 占领。
Q 进入当前武将的地图技能选点，左键施放，右键 / Esc 取消。成功施法后本队本轮行动结束。
F3 为开发用地形覆盖。内景中这些地图快捷键不会穿透到大地图；Esc 关闭内景菜单或返回。
原 MapStitch v5 九区图片、拼接坐标和地形标注保持不变。放大后的独立斜俯视网格包含 10,692 格，并依据原图重新生成通行边、据点范围和渡口两岸落点；渡口落点保持在各自标注的岸边。

存档
大地图顶部“存 / 读”、内景底部“存档 / 读档”，或 F5 / F9 保存和读取。行军中禁用存读。
保存资源、声望、全部地块、等级、施工队列、地标、归属、兵力、位置、行动力、回合。
当前统一存档为 schema 7、grid_revision 3，记录三编队幸存人数、受损守军、武将属性与网格版本；兼容 schema 1–6 及旧网格，并转换旧版格子位置。旧版客户端会拒绝新存档，避免把新格子编号误读为旧坐标。
先写临时文件再替换正式存档；读档先完整校验，损坏存档不会部分覆盖当前战局。
内政布局使用 schema 3 及后续格式。兼容 schema 2 经营存档：保留原有 19 块城市用地、建筑、地形与工程，大城追加 12 块空地。兼容 schema 1 行军存档：保留原据点归属与部队，补上默认经营状态和起始府库。
新启动默认开始西岐新战局；需要主动读档恢复。旧存档保留旧归属，因此不等于新的西岐开局。
保存位置仍使用原“山河 · 九州行军”目录：
macOS: ~/Library/Application Support/Godot/app_userdata/山河 · 九州行军/campaign.json
Godot 其他平台通过 user://campaign.json 访问。

--legacy-fixture 仅给旧行军回归测试保留原起点，不影响正常新战局。
运行自动化 UI 测试时请使用独立测试用户目录，避免覆盖自己的 campaign.json。

当前范围
已可进行建设、升级、邻接布局、地标修复、全势力资源结算、补兵、占领和九州行军。
商军据点须先相邻接战，胜利后占领；中立据点仍可直接占领。朝歌战场可按 B 体验三兵种混战。戟兵接敌，后排弓兵放箭，两翼骑兵发动一次冲锋。
大地图按 B 进入独立演武；实战按 C 接战，R 终结技、Space 暂停、X 倍速、Enter 返回地图。详细规则、三编制槽范围与美术来源见 docs/battle_mvp.md。
每名武将配置自动读条技能、手动终结技、地图技能和被动。每战士气从 50 开始，随实际击杀增加，到 100 可释放并消耗 100；可再次积累。
英雄、戟兵、弓兵与骑兵都有物攻、物防、魔攻、魔防、生命、移动力。攻击和减伤使用真实属性，移动力决定大地图每回合移动预算。地图左侧展示含被动及临时效果的最终属性，右侧展示四技能。
当前可操作的哪吒、南宫适、黄天化分别拥有范围伤害、群体增益、群体恢复地图技能；行军和减益结算也已实现，关联的姬发、闻仲尚无玩家招募入口。参数和范围见 docs/hero_skills.md。
暂未加入野战巡逻 AI、外交、武将养成或封神主线。
等级仍为 UI 占位示例；六项通用属性、技能、资源、兵力、行动力、建设和地标均为真实状态。
建筑三级目前共用基础原画，以名牌等级区分，未制作每级独立美术。
经营测试中的“已建成村庄 / 关隘”截图使用实际建设、回合结算后的状态；新战局保留原有起始建筑数量。
